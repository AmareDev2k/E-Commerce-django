## 📖 About The Project

This project is a fully functional E-Commerce web application. It uses **Django (Django REST Framework)** for a robust and secure backend, **React** for a dynamic, single-page application user interface, and **PostgreSQL** as a reliable relational database. 

### ✨ Key Features
- **User Authentication**: Secure Login & Registration using JWT (JSON Web Tokens).
- **Product Management**: Browse products, view details, search, and filter.
- **Shopping Cart**: Add/remove items and adjust quantities dynamically.
- **Checkout System**: Secure checkout process with shipping address management.
- **Admin Dashboard**: Django admin panel to manage users, products, and orders.
- **Responsive Design**: Optimized for mobile and desktop screens.

---

## 🛠️ Tech Stack

- **Frontend**: React.js, React Router, Redux (or Context API), Axios
- **Backend**: Python, Django, Django REST Framework, Simple JWT
- **Database**: PostgreSQL
- **Styling**: Tailwind CSS / Bootstrap (Update based on your choice)
